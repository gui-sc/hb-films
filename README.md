# HB.Films

Homepage institucional da HB.Films reconstruída com React, Vite e TypeScript.

## Desenvolvimento

```bash
npm install
npm run dev
```

Para gerar a versão de produção:

```bash
npm run build
```

## Direção

O site é tratado como uma experiência cinematográfica empresarial. A linguagem usa somente preto, branco e neutros, com timecode, viewfinder, contact sheet, film strip e timeline como elementos de navegação e ritmo. Os vídeos existentes no HTML legado continuam sendo usados como mídia dos projetos, carregados de forma lazy quando entram perto da viewport.
